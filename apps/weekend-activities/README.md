# Weekend Activities Android

Thin Capacitor wrapper for the live Weekend Activities GitHub Pages site.

- Hosted UI: https://bigcatmellow.github.io/weekend_activites/
- Package ID: `com.bigcatmellow.weekendactivities`
- App name: `Weekend Activities`

The website remains the source of truth. Event updates and ordinary HTML/CSS/JS changes appear in the installed app without rebuilding the APK. Rebuild only for native-shell, package, permissions, signing, or Android behavior changes.
